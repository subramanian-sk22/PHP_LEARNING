Question 1

What will be the output of the following PHP code?

$x = 5;
echo $x++ + ++$x;
?>
Answer: B) 12
$x++ returns 5, then $x becomes 6. ++$x increments to 7 and returns 7. So 5 + 7 = 12.
Question 2

Which of the following is NOT a valid PHP variable name?

Answer: C) $1myVar
PHP variable names cannot start with a number. They must start with a letter or underscore.
Question 3

What is the output?

echo "5" + "10 apples";
?>
Answer: A) 15
PHP extracts the leading number "10" from "10 apples" and adds it to 5, giving 15. A warning is generated.
Question 4

What does the '===' operator do in PHP?

Answer: C) Compares values and types
=== is the strict comparison operator that checks both value and data type. 1 === "1" would be false.
Question 5

What is the output?

$a = "Hello";
$b = "World";
echo $a . " " . $b;
?>
Answer: B) Hello World
The dot (.) operator concatenates strings. " " adds a space between them.
Question 6

Which of the following values is considered FALSY in PHP?

Answer: C) "0"
"0" (string zero) is falsy. "false" is a non-empty string (truthy). -1 is truthy. " " (space) is truthy.
Question 7

What is the output?

echo 10 / 4;
echo 10 % 4;
?>
Answer: A) 2.52
10/4 = 2.5, 10%4 = 2 (remainder). Since there's no separator, output is "2.52".
Question 8

How do you define a constant in PHP?

Answer: B) define("PI", 3.14);
Constants are defined using define() or const keyword. They don't use $ sign.
Question 9

What is the output?

$x = 10;
$y = 0;
var_dump(empty($y));
var_dump(isset($x));
?>
Answer: A) bool(true) bool(true)
$y = 0 is empty (falsy), so empty() returns true. $x = 10 is set and not null, so isset() returns true.
Question 10

What is the output?

$a = true;
$b = false;
$result = $a and $b;
var_dump($result);
?>
Answer: A) bool(true)
Due to operator precedence, $result = $a happens first (assigning true), then "and $b" is evaluated but doesn't change $result.
Question 11

What is the output?

$str = "Hello";
echo $str[1];
?>
Answer: B) e
String indexing starts at 0. $str[0] is 'H', $str[1] is 'e'.
Question 12

Which function is used to check if a variable is set and not NULL?

Answer: B) isset()
isset() returns true if the variable is set and is not NULL. empty() checks for falsy values.
Question 13

What is the output?

echo 1 == "1" ? "true" : "false";
echo 1 === "1" ? "true" : "false";
?>
Answer: B) truefalse
1 == "1" is true (loose comparison). 1 === "1" is false (different types: integer vs string).
Question 14

$var = 12.7;

(int) casting truncates the decimal part. It doesn't round the number.

Question 16

What is the output?

$a = "10 apples";

echo $a + $b;

Question 17

What does the '.' operator do in PHP?

The dot (.) operator joins two strings together.
Question 18

What is the output?

echo "5" . 2;
?>
Answer: B) 52
The dot operator concatenates. "5" . 2 gives "52" (string concatenation).
Question 19

Which magic constant returns the current line number?

Answer: B) __LINE__
__LINE__ returns the current line number in the file. __FILE__ returns the full file path.
Question 20

What is the output?

$x = 7;
$x += $x++ + ++$x;
echo $x;
?>
Answer: D) 25
Initially $x=7. $x++ returns 7, $x becomes 8. ++$x increments to 9, returns 9. Sum = 16. Then $x += 16 → 9 + 16 = 25.
